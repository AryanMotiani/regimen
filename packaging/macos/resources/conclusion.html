The lock agent is installed

Your browser opens Regimen to connect the agent. Restart your browsers once so the new settings apply.

If the browser did not open: open Terminal and run sudo regimen-agent pair. It opens a fresh pairing link and prints a code you can type in Regimen, Settings, Lock agent.

Emergency recovery, if the agent ever breaks: Applications, Regimen Emergency Recovery. To remove the agent: sudo regimen-agent uninstall.
