Privacy policy

Regimen web app, browser extension and lock agent. Last updated 25 September 2026.

The short version: everything you put into Regimen stays on your own computer.

  • No account, no sign-in, no email address.
  • No analytics, no tracking, no ads, no crash reporting.
  • No Regimen server. We never receive your data, so we can't sell, share or lose it.
  • The code is open source, so anyone can check these promises.

What Regimen stores, and where

Your tasks, habits, schedule, blocked sites, focus history, settings and accountability log are stored in the browser extension's local storage on your computer. If you use the website without the extension, they are stored in your browser's local storage for that site instead. Your PIN and recovery code are stored only as salted hashes (PBKDF2), never in readable form.

You can export everything as a JSON file (Settings, Backup) and delete everything (Settings, Reset). Removing the extension deletes its data.

What leaves your computer

Nothing that Regimen collects. Specifically:

  • The extension makes no network requests except to the optional lock agent on your own computer (127.0.0.1), and a quick check that the Regimen website is online before it opens it for you. That check sends nothing about you.
  • The study room's music and ambience are generated live in your browser. No audio is streamed and nothing is downloaded while you listen.
  • The website is a static page hosted on GitHub Pages. Like any web host, GitHub may keep standard server logs (such as IP addresses) when the page loads. See GitHub's privacy statement. The website itself sets no cookies and runs no analytics.
  • Browser stores (Firefox Add-ons, Edge Add-ons, Chrome Web Store) check for extension updates as your browser normally does. That is between your browser and the store.

The browser extension's permissions, and why

Access to all websites To block any site you choose, when you choose, and to send already open tabs of a blocked site to the "blocked" page when a block starts. The extension does not read, collect or send the content of the pages you visit.
declarativeNetRequest The browser's built-in way to block requests to the sites on your list. The browser does the matching, not our code.
tabs To find open tabs of a site that just became blocked, and to bring you back to the Regimen tab after installing.
storage and unlimitedStorage To keep your data on your computer, including a long task and focus history.
alarms To start and end blocks on schedule, even when no Regimen tab is open.
notifications To tell you when a block starts or ends.
Helper script on web pages A tiny script lets the Regimen website talk to the extension. It runs only on the Regimen website (and on a copy on your own computer that you allowed), never on other sites, and it does not read the page.

The lock agent (optional program)

If you install the lock agent, it runs on your computer with administrator rights, because blocking system-wide needs them. It:

  • receives your rules from the extension over a private connection on your own computer (127.0.0.1, port 47621). It answers only the Regimen extension, which proves itself with a secret created when you paired them.
  • writes the blocked sites into your system's hosts file, only between its own marked lines, and keeps a backup of the original.
  • sets official browser policies that turn off Secure DNS and private windows (and, in strict mode, lock the extensions page and developer tools). Uninstalling removes them.
  • stores its settings, the last rules it received and a short log in a folder only administrators can read.

The lock agent never contacts the internet. After installing, it opens the Regimen website in your browser with a one-time pairing code. The code sits after the # in the address, which browsers never send to the web server, and it stops working after 30 minutes or first use.

Children

Regimen is made for students of any age. It collects no personal information from anyone, including children.

Changes

If this policy ever changes, the new version is published here and in the project's history on GitHub. We will not start collecting data without saying so clearly first.
